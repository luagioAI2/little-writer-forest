## 十七、网页 / 桌面**不接**云端转写（10-03 家长定）→ L§五十三
★★ **别再提议「给网页接一条 REST 转写」** —— 家长原话：「网页本身就可以通过输入法的语音输入的」。网页的答案是**键盘 + 输入法自带语音**（Windows `Win+H` / macOS 听写 / 手机输入法麦克风）：比接 REST 更快、不花钱、不暴露密钥、不用维护代理。
★★ **提示的判据是 `isStreamingSupported()`，不是 `!canTranscribe`**（`VoiceComposer.tsx` 键盘入口旁那段说明）：后者在「APK 忘打密钥」时也为假，而那种情况在手机上，说「请在手机 App 里用」是错的。守卫在 `VoiceComposer.test.tsx` 的「★ 判据是…」—— **只有下半格**（支持流式 + 没配密钥）能钉住这个区别；**判据类守卫必须覆盖「两边都为假、但原因不同」那一格**，否则它看着绿、其实什么都没钉住。
