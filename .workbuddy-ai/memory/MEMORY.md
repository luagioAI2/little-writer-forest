## 一、AI 边界（最硬，09-19）→ LESSONS §一

**判据是「内容从哪来」，不是「谁在操作」**：字是**孩子说的** → 可换/删/挪/插；**AI 造的** → 不许润色/扩写/想结尾。

- ★ 第一道防线 = **接口形状**（`ParsedEditInstruction` 无"正文"字段）；★★ 第二道 = **来源闸门**（§十）。
- 「要 AI 代写」走 `refuse`、"模型自造字"走 `invented` —— **都不许混进 `unknown`**。
- ⚠️ AI 介入的编辑记录必须标 `by:'ai'`；鼓励语/回执不许说成「你自己改的」。

## 二、其他底线 → LESSONS §二

改作文找不到目标 / 出现多次 → **停下问孩子，不擅自改**。吉祥物是给**已有角色**补身体，不是新增角色。

## 三、★★ 被判断的字符串 ≠ 被存下去的字符串（09-23）→ LESSONS §二十二

- ★★ **归一化排在所有判定之前、只做一次**；**判定与落库必须读同一个变量**。
- ⚠️ 这类 bug **不报错、不崩、计数还是 `0`** ➜ **改完必须看计数从 0 变非 0**。
- ★★ **守卫写完立刻单独跑它的测试**：那条测试**早写好、只是没跑** → 它红着、数据却已落库。**"测过了"和"测存在"是两件事。**

## 四、09-19 / 09-20 报告结论 → LESSONS §三/§四/§五/§六

- **不许用本地模板冒充 AI 产出**：模型少给字段 → **补问一次**；还不行 → **整份退回本地**并标 `engine:'local'`。⚠️ `WorkScore` 与 `ModelEssay` **各自独立定引擎**；**界面上的 `engine` 必须说真话**。
- ★ **一个设置项有多条执行路径，就必须每条都读**。**能做的做，做不到的说**（**如实点名**）。**装作做到了比做不到更坏。**
- **模板依据是「内容里有什么」，不是「它归到哪一类」**；**同一判定只许有一个函数**（`resolveKind`）；**人工挑过的词表不许再过启发式过滤**（出路是**加词表**）。
- ⚠️⚠️ **两个上限只补一个 = 没补** ➜ **判定基于裁剪后的正文；家长点名的句子不参与裁剪。**
- ★★ **正则前/后缀枚举每漏一个变体 = 一个 100% 失败的口子**（曾漏「把」）；★ **插入点是"词"的边界**；⚠️「前/后」**不收**。
- ★ **标点是一整类缺失**（`replace-punct` 存**真符号**，`PUNCT_PATTERNS` 排最前）；⚠️ **`replace`/`replace-punct` 消歧必须共用一份判定**（`replacePairOf`）—— 漏了"面板弹不出来"，**不报错、只是没反应**。

## 八、验证基线（改动后应保持）→ LESSONS §十

- `npm run lint` → **0 error / 8 warning**（8 条是既有基线，别"顺手修"）；`npx vitest run` → **35 files / 729 passed + 10 skipped**（09-23 实测）。★ **类型检查跑 `npm run lint`，别敲 `npx tsc --noEmit`** —— 根 tsconfig 是 solution-style，后者**编译 0 文件却 exit 0**，假绿。

## 十、★ 改作文只走 AI + 来源闸门（09-21，**已实施**）→ **LESSONS §十三 / §14.1–14.4**

- **`editLocally` 的调用点与定义都已删**。⚠️ **两处兜底要一起删** —— `catch` 那支才是真正接住网络/密钥/超时的地方。**为什么必须删**：退回本地**不报错、不崩，它只会成功** → "AI 根本没跑"被彻底掩盖。
- 文案**缺什么说什么**（没配 / 缺字段 / 没听懂 → **原样端出 `r.message`**）。⚠️ **`refuse` 不走这条路**（`ok` 是 `true`）。★ **DeepSeek 思考模式**默认**开启**，**思考模式下 `temperature` 不生效** → 只有 `parseEditInstruction` 传 `thinking:false`。
- ★★ **来源铁律**（`checkProvenance`）：改完后正文每个字必须来自 **①原文** 或 **②孩子那句话**；写入侧（`to`/`text`）必须是**孩子那句话的子串**（**连续匹配**）。
- ⚠️⚠️ **唯一的口子 = 标点「名字→符号」白名单**（「句号改成叹号」→ 指令里是「**！**」，**不是那句话的子串**）→ 照字面卡会**把改标点一整类 100% 误杀**。★ 只有他**点过名的**标点才算"他说过的"。

- ★ **指位 `near`/`side`/`pick`** 已推广到 `replace`/`delete`：**只声明一次**、**定位只有一份判定**（`locateOccurrence`）；**`near` 只在两种情况才用**：① 目标出现多次 ② 孩子没说那个字、只说了它相对谁。
- ⚠️ **记录面板往后找句末要从 `to - 1` 起步**，否则会把**没被改的下一句**摆进「原文」栏。★ 与 `changedSpan` **共用 `diffBounds`**，但 `changedSpan` 自身仍**被禁** —— **别一起复活**。

## 十一、写作台：麦克风**上下各一个**常驻槽（定稿）→ **LESSONS §十二（动前必读）**

**识别状态在上、提示语在下**：上槽 `h-12`（闲着时**空**）→ 麦克风（84px）→ 下槽 `h-12`（提示语）。

- ★★ **两个槽必须永远渲染 + 高度都写死 `h-12`** → 总高度恒定 → 按下时按钮**一动不动**。⚠️ 破任一条就重新引入「刚按下去就松开」（凭空长出状态条 → 按钮下推 → 手指还在原位 → `pointercancel` → **录音当场丢掉**）。
- ★★ **两条守卫各守一半，都不许删**；⚠️ 「状态在上」那条**光断言 DOM 顺序不够**（"提示语在上"也能过）→ **必须再断言"内容各就各位"**。

## 十二、★ 输入框的值要「落盘」才算数（09-22）→ **LESSONS §十五**

- ★★ **不许把"保存"押在失焦上**：点头像那一下 tap **不保证先让输入框失焦** → 名字压根没存；⚠️⚠️ **而输入框还显示着新值，看着像存上了**。这种 bug 光看界面永远发现不了，**必须靠单元测试**（jsdom 里点击天然不失焦）。
- ★★ **落盘前必须有空值兜底**：清空再失焦会在存档里留下 `''` → 渲染成**一片空白**。➜ 空名字不是"没名字"，是"还没起名" → **落盘时就换成默认名**。
- ⚠️ **纯逻辑修复加不进 `_verify-apk.mjs` 的 `FEATURES` 表**（没有新文案）→ 守卫放单元测试，**别硬凑特征串**。

## 十三、★ 一个函数有多个「出口」，就会有人选错（09-22）→ **LESSONS §十六**

- 根因：`ComposePage` 的 `reset(backToSetup)` 有两个分支，背诵那步传了 **`reset(false)`** → 新建空稿跳进写作页 → 孩子领完奖看到**一篇同名的空白作文**。
- ★★ **判据：某分支只有一处调用、而它的注释在解释一个不存在的东西 = 误用的强信号。** `grep` 那个参数值的**全部**调用点 —— **只有一处就该起疑**。
- ★★ **修法是删掉分支，不是加测试**：出口只剩一种 → **"选错出口"结构上不可能再犯**。
