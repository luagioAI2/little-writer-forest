# 小笔苗（little-writer-forest）· 项目约定索引

> **这是索引，不是全文。** 只留"必须照做"的那一句 + 判据。
> **动到某一节的代码之前，先去 `LESSONS.md` 读同名那一节** —— 家长原话、踩坑过程、失败反例都在那里。
> 日常流水记在 `YYYY-MM-DD.md`。
> ⚠️ 源码是 **CRLF**；脚本做多行替换前先归一成 `\n`，否则"看着一模一样却命中 0 处"。

## 一、AI 边界（最硬的一条，09-19 定）→ LESSONS §一

家长：「不许 AI 帮**写**（生产内容），不是不许改写。…但不许 AI 自己生产内容 —— 类似『给这个句子加点比喻』都不行。」

**判据是「内容从哪来」，不是「谁在操作」**：字是**孩子说的** → 可换/删/挪/插；内容是 **AI 造的** → 不许润色/扩写/加比喻/想结尾。

- ★ **第一道防线 = 接口形状**：`ParsedEditInstruction` 里**没有"正文"字段**。
- ★★ **第二道防线 = 来源闸门**（§十四）：形状只挡"整篇"，挡不住模型往 `to`/`text` 里塞自创的字。
- 「要 AI 代写」走 `refuse`，"模型自己造字"走 `invented` —— **都不许混进 `unknown`**（回"没太听懂"孩子会一直换说法）。
- ⚠️ AI 介入的编辑记录必须标 `by: 'ai'`；鼓励语/记录标题/回执都不许说成「你自己改的」。

## 二、其他底线 → LESSONS §二

- 改作文找不到目标 / 出现多次 → **停下问孩子，不擅自改**。这是好设计，别优化掉。
- 吉祥物是给**已有角色**补身体，不是新增角色。

## 三、AI 产出的不许用本地模板冒充（09-19）→ LESSONS §三

- 模型少给字段 → **补问一次**；还不行 → **那份对象整份退回本地**并标 `engine: 'local'`。
- ⚠️ `WorkScore` 与 `ModelEssay` 是**两个对象**，各自独立定引擎 —— 绝不许「模型给的分 + 本地总评」。
- **界面上的 `engine` 必须说真话**，否则"配置没生效"被伪装成"功能没实现"。
- ⚠️ `scoreWork`（只评分那条）App 里没人调，仍是旧的静默降级写法。

## 四、「更好的写法」要结合图和孩子写的（09-19 第二次报）→ LESSONS §四

- 收到「要结合 A 和 B」先问：**输出里有没有跟 A、B 都无关的整句？** 有 → 问题在**生成层**。
- ★ **模板依据是「内容里有什么」，不是「它归到哪一类」**。
- ★ **同一个判定只许有一个函数**（`resolveKind`）。
- **人工挑过的词表不许再过启发式过滤**；被误伤的出路是**加词表**，不是放松守卫。

## 五、家长设置里的提示词，两条路都要读（09-19 第三次报）→ LESSONS §五

- ★ **一个设置项只要有多条执行路径，就必须每条都读**（`extraPrompt` 曾只有 AI 路在读，一降级就**静默丢弃**）。
- **能做的做，做不到的说**（在降级警告里**如实点名**）。**装作做到了比做不到更坏。**
- ⚠️⚠️ **两个上限只补一个 = 没补** ➜ **判定必须基于裁剪之后的正文；家长点名的句子不参与裁剪。**
- **亮点不许宣称正文里没有的修辞**（与生成句子的函数读**同一份模块级词库**）。
- 优先级：① 写人时第一句必须是这个人 ② 画面句 ③ **家长点名的修辞** ④ 通用套话。

## 六、改作文「理解不行」（09-20 第四次报）→ LESSONS §六

- ★★ **孩子最自然的说法（带「把」）100% 失败**：正则前缀只写 `(?:在)?`，漏了「把」。
  ➜ **正则的前缀/后缀枚举，每漏一个变体就是一个 100% 失败的口子。**
- ★ **插入点是"词"的边界**（anchor 匹配「操场」，孩子心里的词是「操场上」→ 往后贴一格）。
  ⚠️ 「前/后」**不收**（会误伤「小明后来走了」）。
- ★ **孩子会把"落脚点"念进来，而它本来就在正文里** → 与紧接的正文尾部重合 **≥2 字**就削掉。
- ★ **标点是一整类缺失**：`kind:'replace-punct'`，`from`/`to` 存**真符号**。
- ★ **`PUNCT_PATTERNS` 必须排在通用替换之前**；「最后/第一个」两条**必须排在"参照物"那条之前**。
- ★ **有多个候选就停下问，但孩子自己指好了就别问**（`ambiguous` vs `pick:'last'`）。
- ⚠️ **`replace` 与 `replace-punct` 的消歧分支要共用一份判定**（`replacePairOf`）—— 漏了会"面板弹不出来"，**不报错、只是没反应**。

## 七、设置项/默认值改了，老存档不跟着走（09-20 / 09-21）→ LESSONS §七

- 改 `defaultAiConfig()` **只对"新装"生效**（`{...defaultAiConfig(), ...s.ai}` 会盖掉）→ 必须**同时**加迁移（只换"我们预置过的旧名 + 官方 base_url"，家长自己填的一律不碰）。
- ★ **同一字符串在多处各写一遍 = 迟早漂移**。只有一份的：`DEFAULT_DEEPSEEK_MODEL`、`DEFAULT_CHILD_NAME`。
- ⚠️ **模型名**：V4.1 Flash 正式调用名是 **`deepseek-flash`**；`deepseek-v4.1-flash` 是**阿里百炼**的名字。
- ★★ **判据升级为"每个配置对象都必须自洽"**：加字段时问 **"老存档缺这个字段时，拼出来的东西自不自洽？"**，不自洽就必须写迁移。
  ⚠️ 同一坑的另一面是**共用字段名**（两条路的密钥都叫 `apiKey`）—— 切路由时必须换密钥，否则就是把 A 的凭据递给 B。

## 八、新手引导（09-20）→ LESSONS §八

- **`onboarded` 与 `guideDone` 是两个开关，不许合并**（问 vs 教）。
- ★ **第一目标不是"介绍功能"，是"让他把手势做一遍"**（孩子会去**点**麦克风 → 以为坏了）。
- ★★ **"按住"不是唯一手势** ➜ **`canHoldToTalk(cfg)`**，`VoiceComposer` 与引导**共用这一份判定**。
- ★ **引导里绝不申请麦克风权限**（纯脚本，不碰 `getUserMedia`）。
- **引导里说的东西必须都是真的**。

## 九、协作方式（09-20 家长定，最高优先）→ LESSONS §九

家长：「stop doing unrequested work. Confirm with me before proceeding. do not deploy or commit anything without my explicit permission.」

- ★★ **不做没被要求的事** —— 额外发现的 bug **不是功劳** ➜ **发现了先报告、等确认，再动手。**
- ★★ **不许 build / 打 APK / 部署 / 提交**，除非明确说可以。

其余工程习惯（注释写"为什么"、颜色改动 hex 与 `rgb()` 都要扫、SVG 尺寸不许写死、验收要走到打包产物、`FEATURES` 每加功能补一条、判据用 bundle 名/sha256 不用体积、新守卫先看它红一次、`as T` 骗不过运行时、变异脚本要 `trap … EXIT`）→ **LESSONS §九**。

## 十、验证基线（改动后应保持）→ LESSONS §十

- `npm run lint` → **0 error / 8 warning**（8 条是既有基线，别"顺手修"）
- `npx vitest run` → **33 files / 693 passed + 10 skipped = 703**（09-22 实测）
- ★ **类型检查跑 `npm run lint`，不要敲 `npx tsc --noEmit`** —— 根 tsconfig 是 solution-style，后者**编译 0 个文件却 exit 0**，是假绿。
- `npm run build` 偶发文件锁 → **先清 dist 再 build**。
- 临时探针 / 变异脚本**用完删掉**；补丁要**断言命中 1 处**；★ **光看 exit code 不够**，至少抽两条手工确认红的是**该红的那几条**。
- 老用例被新守卫弄红时，**先查夹具合不合法、再查那条断言是不是"替身"**，最后才动守卫。
- `__gallery.test.tsx` 偶发 EPERM 是**环境问题，重跑即过**，别改那个用例。

## 十三、★ 改作文只走 AI，失败不许静默降级（09-21）→ **LESSONS §十三（全文）**

家长：「改作文 **必须是 AI 模型 处理**。」

- **`editLocally` 的调用点与定义都已删**（`!r.ok` + `catch` + 未配 AI 三个分支）。⚠️ **两处兜底要一起删**：`catch` 那支才是真正接住网络/密钥/超时的地方。
- **为什么必须删**：退回本地**不报错、不崩，它只会成功** → "AI 根本没跑"被这次成功彻底掩盖，家长只会去改设置、改说法，永远查不到。
- 文案**缺什么说什么**（没配 / 缺字段 / 没听懂 → **原样端出 `r.message`** / 抛异常 → 提示去「测试连接」）。
- ⚠️ **`refuse` 不走这条路**（`ok` 是 `true`，会走到 `applyEdit` 说「这句得你自己写」）。
- ★ **DeepSeek 思考模式**：默认**开启**、effort `high`；**思考模式下 `temperature` 不生效**（静默忽略）→ `callChat` 的 `thinking?: boolean` **只有 `parseEditInstruction` 传 `false`**。

## 十四、★ 来源闸门 + 指位（09-21，**已实施**）→ **LESSONS §14.1–14.4（全文）**

家长：「我的目的是 **修正作文**。通过大模型修改。但是要限制，**AI 不能自创内容**。」

- ★★ **来源铁律**（`domain/provenance.ts` 的 `checkProvenance`）：改完后正文里每个字必须来自 **①原文** 或 **②孩子那句话**；写入侧（`to`/`text`）必须是**孩子那句话的子串**（**连续匹配**）。
- ⚠️⚠️ **唯一的口子 = 标点「名字→符号」白名单**：孩子说「句号改成叹号」，指令里是「**！**」，它**不是那句话的子串** → 照字面卡会**把改标点一整类 100% 误杀**。★ 只有他**点过名的**标点才算"他说过的"；多字符标点（`……`/`——`）**整体先摘**。
- **定位侧**（`from`/`target`/`anchor`/`near`）**不在这里查原文**（那是 `applyEdit` 的活），闸门只卡 **`MAX_SPAN_CHARS = 40`**。越界 → `reason:'invented'`，★★ **不许并进 `unknown`**。
- ★ **指位 `near`/`side`/`pick`** 已推广到 `replace`/`delete`：**只声明一次**（`voiceEdit.ts`）；**定位只有一份判定**（`locateOccurrence`，**三支各写自己的措辞**）；**`near` 只在两种情况才用**：① 目标出现多次 ② 孩子没说那个字、只说了它相对谁。
- **记录面板三行**：`EditOperation.said` 逐字原话，只有 `by:'ai'` 才填。⚠️ **往后找句末要从 `to - 1` 起步**。★ 与 `changedSpan` **共用 `diffBounds`**，但 `changedSpan` 自身仍**被禁** —— `sentenceChange` 安全的前提是**两端出自同一次定点拼接**，**别一起复活**。

## 十五、★ 输入框的值要「落盘」才算数（09-22 家长报）→ **LESSONS §十五**

家长：「另外 设置了名字。再选择头像，名字就清除了。这个 BUG 没修复。」（`SettingsPage` 昵称，同一段代码里两个毛病）

- ★★ **不许把"保存"押在失焦上**：`onBlur={commit}` 只在失焦时存 —— 而**点头像那一下 tap 不保证先让输入框失焦** → 名字压根没存；⚠️⚠️ **输入框还显示着新值，看着像存上了**。这种"看着对、其实没存"的 bug 光看界面永远发现不了，**必须靠单元测试**（jsdom 里点击天然不失焦，能直接复现）。
- ★★ **落盘前必须有空值兜底**：清空再失焦会在存档里留下 `''` → 在 `{childName} · 三年级`、`XX 的森林` 里渲染成**一片空白** = 家长说的「名字被清除」。➜ 空名字不是"没名字"，是"还没起名" → **落盘时就换成默认名**，不能等渲染时再补。
- ★ 默认名收成一份 **`DEFAULT_CHILD_NAME`**（`domain/types.ts`）—— 原本 `db.ts` / 引导页 / 设置页**三处各写一遍**（同 §七）。
- ⚠️ **纯逻辑修复加不进 `_verify-apk.mjs` 的 `FEATURES` 表**（没有新的用户可见文案）→ 守卫放单元测试，**别硬凑特征串**。

## 十六、★ 一个函数有多个「出口」，就会有人选错（09-22 家长报）→ **LESSONS §十六**

家长：「背诵完 点领取奖励。好像回到的页面不对，还是在当前写的。是不是不合理。」

- 根因：`ComposePage` 的 `reset(backToSetup)` 有两个分支，背诵那步传了 **`reset(false)`** → `beginWith(同一题目)` 新建空稿、跳进写作页 → 孩子领完奖看到**一篇同名的空白作文**。
- ★★ **判据：某分支只有一处调用、而它的注释在解释一个不存在的东西 = 误用的强信号。**（`reset(false)` 全项目只用一次；注释说的「再写一篇」按钮 `grep` 不到。）查这类 bug 最快的办法是 `grep` 那个参数值的**全部**调用点 —— **只有一处就该起疑**。
- ★★ **修法是删掉分支，不是加测试**：零调用者的分支留着 = 下次又有人传错；删掉 = **出口只剩一种，"选错出口"结构上不可能再犯**。
- ⚠️ 这条**没加自动化测试**：bug 在**接线**上，而 `step` 是页面内部 state 没法播种；走到背诵步要完整驱动四步，且写作台正文**只能语音输入**。取舍，不是"不需要守" —— 详见 LESSONS §16.4。
