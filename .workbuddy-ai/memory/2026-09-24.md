### 15.3 ★★★ DBpedia 的两个坑（都**不报错**）

Château / Park_Güell / Český / Zócalo / Copán / Gorée）。
⭐ 正解：`const iri = (w) => RES + w`；传输层编码交给外层 `encodeURIComponent(query)`。
⚠️ 我是靠 `lookup.dbpedia.org` 反查出真名 `Sagrada_Família` 才发现的。

### 18.4 ★★★ AI 散文按钮「让小鸟写一篇」

**为什么必须走本地端点、不能让浏览器直连服务商**：
① 密钥会出现在网页里（F12 就看见，截图也会带出去）；
② `api.deepseek.com` 不一定给 CORS 头，直连多半被拦；
③ 存 localStorage 才谈得上"刷新后复用" —— 而这个页面**不该存密钥**。

➜ 加 `POST /__draft-essay`（同一个 dev 插件里，`apply:'serve'`）。
密钥只走「浏览器 → 本机 dev server → 服务商」，**用完即弃**：
不写文件、不回显、不打日志、**不读 `process.env`**。

★★ 三条安全规矩（都写进 `vite.config.ts` 注释了）：
1. `apply: 'serve'` —— 构建产物里没有这个端点；
2. **只收本机请求**（`isLoopback`）—— 根配置 `server.host: true` 让 dev server
   监听 `0.0.0.0`（联调 APK 要用），所以"能连上"**不等于**"是本机"；
3. **故意不读环境变量** —— 只花"调用方自己递上来的"那把密钥。
   一旦去读 env，第 2 条就成了唯一防线，漏一次就是替别人付钱。

★★ **`redact()`** —— 服务商 401 的报错**会把 `Authorization` 原样回显**
（实测 DeepSeek 会打码成 `****pear`，但不能指望每家都打）。
那段文字会被转给前端、显示在提示条上、被家长截图发出去。所有 `send()` 的错误都过它。

★ **服务端顺手收拾"形状"**（`cleanEssay`）：半角逗号 → 全角、去 emoji、
去 markdown 记号、去开头像标题的一行、**单换行也当分段**（否则 `split('\n\n')` 数出 1 段，
`travelContents.test.ts` 直接红）。**一个字都不替它改**，只改形状，并回 `notes` 如实报出来。

★ **只填进编辑框，不落盘** —— 家长看过、改过，自己点「保存到文件」才算数。

★ `thinking: {type:'disabled'}` **只对 DeepSeek 发**，且这里**必须关** ——
思考模式下 `temperature` 会被**静默忽略**（官方原话"不报错也不生效"），

### 18.7 写 e2e 时踩的 3 个技术坑

1. **★★ 假服务商不用真密钥**：本机起一个 http server 返回假的
   `choices[0].message.content`，把那次 POST 的 `baseUrl` 改写指向它。
   ➜ 整条链路（清洗 / 不落盘 / 密钥不泄漏）**全都能测，且不花一分钱**。
2. **⚠️ 不能用 puppeteer 的请求拦截改 body** —— 改了 body 就得改
   `Content-Length`，而 **CDP 把 `content-length` 列为 unsafe header 直接拒收**
   （`Protocol error: Unsafe header: content-length`）；不改的话服务端按旧长度读，请求吊死。
   ➜ 改成在**页面里包一层 `window.fetch`**，同样不动产品代码。
3. **⚠️ `new URL(...)` 不能用** —— 这个脚本顶上那个页面地址常量**就叫 `URL`**，
   把全局构造器遮住了（`TypeError: URL is not a constructor`）。用 `resolve(process.cwd(), ...)`。
4. **⚠️ 一条回归会伪装成一片** —— 弹窗关不掉时它的灰色背景盖住整页，
   后面每次 `page.click` 都点在背景上 ➜ 连着红 5 条。加个「确保弹窗是关的」兜底，
   让一条回归只报一条。
