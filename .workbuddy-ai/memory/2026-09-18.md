## 一、先回答问题：评价走 AI 吗？

**代码支持走 AI，但默认配置下没走。**

`submitWork` → `scoreAndRewrite`，里面：

```
if (!shouldUseRemote(opts.cfg)) { ...走本地... }
```

而 `shouldUseRemote` 要求 `mode === 'remote'` + 密钥非空，
`defaultAiConfig()` 给的是 `mode: 'local'` + 空密钥 —— 所以**现在跑的是本地引擎**。
（09-17 已经把 `AI_TEST_API_KEY` 那个"填了 key 就自动切远程"的缝留好了，
 填上就真的走 AI。）

## 二、★ 真 bug：图**根本没传给 AI**

`buildScoreAndRewriteUserMessage` 完全没读 `opts.images` ——
配图只喂了本地引擎。于是「看图作文」里最要紧的那半（图里有什么）
AI 根本不知道：点评只能泛泛而谈，改写也容易漏掉图上最显眼的东西。

**修法**：新增 `describeImages()`，把配图翻成文字进提示词。

- 描述来源优先级：手写 `caption`（若真是描述）→ `SceneMeta.hint` → `label`
- `SceneMeta.hint` 本来就是为这个准备的，它的注释写着
  「一句话中文描述：画面里有什么，**作为 AI 提示**」
- ★ **「第 1 幅」这种只是位置标记，不能当描述发过去** ——
  用 `POSITION_ONLY = /^第\s*[一二三四五六七八九十\d]+\s*[幅张]$/` 挡掉。
  这个坑很实在：`builtinLibrary` 给多图题的 caption 就是「第 N 幅」，
  不挡的话发过去的"画面描述"就是"第 1 幅"。

**为什么用文字而不是真发图片**（重要，别以后又来改）：
- 内置配图是程序化 SVG，**没有 URL 可以传**
- `deepseek-chat` 本身不吃图（要换视觉模型）
- 文字描述任何模型都能用，也不挑图源

## 三、附加提示词：从"背景噪音"变成"必须落实"

以前 `家长附加要求：xxx` 只是跟在「类型：」后面的一句话，模型很容易忽略。
现在单独成块 + 明说：

```
【家长附加要求 —— 必须落实】
{extraPrompt}
（如果这条要求和上面的默认标准冲突，以家长这条为准。）
```

### 14.1 话筒按钮下移（已完成）

「正在听」那个框原来渲染在按钮**上面**，一按就多出 ~60px，
把按钮顶下去，手指底下换了元素 → 浏览器发 `pointercancel` →
原来的 `onPointerCancel={cancelHold}` 把整段录音**丢掉**。

修法两条：
1. 状态框挪到按钮**下面**的固定高度槽位（`h-12`），换内容不换高度；
2. ★ `pointercancel` 改成走**收尾**（`endHold`）而不是放弃 ——
   `pointercancel` 不是「手指滑出按钮」（有 `setPointerCapture`，
   滑出去再松手是 `pointerup`），它是系统级打断：
   来电、通知栏、系统手势、布局抖动。孩子**确实说了话**，
   丢掉是错的。真·放弃留给 `onBlur`。

### 14.2 ★★ 「更好的写法」没结合图片 / 没结合孩子的内容（已完成）

家长说得准，而且**是两个独立的真因，都是管线断了，不是模型不行**：

**真因 1：`images` 从来没往下传。**
`buildModelEssay(inp)` 收下了 `inp.images`，但适配层调 `composeModelEssay`
时压根没传 —— `ComposeModelEssayInput` 里**根本没有 images 字段**。
所以本地引擎完全不知道图上有什么。

**真因 2：素材抽取只认 5 张固定词表，名物全被丢掉。**
词表是「角色位」（人物/地点/时间/物件/事件）。
孩子写「天上有一条彩虹」—— 彩虹不是人物、不是地点、
也不在物件表里，**被整条丢掉**。抽出来只剩 `person: 小明`、`place: 校园`，
于是正文生成成「远远望去，校园铺开去，像是被谁用画笔轻轻涂过」
—— 这就是家长说的「写了一段不相关的内容」。
探针实测：彩虹、小明**一个字都没进正文**。

**修法**（`modelEssay.ts` 新增「一·五 具体名物」一节）：
- `IMAGERY_GROUPS` —— 画面词表，按「怎么写它」分组（sky/plant/animal/object/water），
  ~200 词，覆盖 assets/scenes.tsx 里 100+ 张插画的 hint 用词
- `extractConcrete(text, limit, preferSpecific)` —— 词表命中（**长词优先**）+
  量词短语兜底（`MEASURE`），再把结果按需排序
- `buildImagerySentences(items, rng)` —— 给每个名物一句
  「我最先注意到的是X。」+ 反应句 +（仅第一件）分组补充句
- `composeModelEssay` 里：孩子写的排前 2，图上才有的补第 3

### 14.3 这一段踩到的四个坑（都是真红过的）

| 坑 | 症状 | 修法 |
|---|---|---|
| 量词兜底抽到「上玩」 | 「操场上**玩**」里的「场」也是量词 → 抽出「上玩」，把彩虹挤出名额 | `JUNK_CAPTURE` 加方位词 `上下里中外前后边` |
| 排序按词表顺序 | 「雨」在词表里排在「彩虹」后面，正文就从彩虹写起，不顺孩子的叙述 | `extractConcrete` 默认按**出现位置**排 |
| 图注里「草」挤掉「水洼」 | 「草地上有两摊水洼」按位置排 → 草在前；但草是泛景，水洼才是这场雨的记号 | 图注走 `preferSpecific=true`（按字数排） |
| 补充句单独占位 | grade 4 只留 4 句 → 补充句吃掉一个名额，奶奶的「老花镜」被裁掉 | 补充句**拼进同一句**里，不单独占位 |

★ 还有一条设计约束：写人（`kind === 'person'`）时第一句必须是**这个人**，
不能是**这个人的东西** —— 「我最先注意到的是摇椅」放在写奶奶的稿子里就不像写人了。

★ 反应句**不许重复**：从池子里随机挑，不排重就会挑到同一条，
正文里印两遍一模一样的句子（这个项目最老的一条坑）。
测试**不能靠真随机源**（撞不撞看运气），要喂 `() => 0` 的假随机源。

## 十五、UI 年轻化（v3 → v4）

家长选了方向：**「配色更亮更跳」+「加角色和动效」**（多选题，两项都要）。

诊断先说清楚：v3 的「老气」不是随手写的，是设计语言本身决定的 ——

### 15.1 配色：只改**值**，不改**名**

关键决定：**保持令牌名不动，只重算颜色值**。
全项目所有 `bg-inkleaf-*` / `text-amber-leaf-*` 自动跟着变，
不用改任何一个组件 —— 这是改动量最小、最不容易漏的做法。

重算方法（有讲究）：把旧值转 HSL，**明度几乎不动，只提饱和**，
浅色档再额外提亮一点。这样 v3 调好的对比度全部沿用，不会翻车。

| 令牌 | v3 | v4 |
|---|---|---|
| inkleaf-500（主色） | `#2f7a5c` | `#10a368` |
| inkleaf-600（主按钮/文字） | `#26624a` | `#0c7c4f` |
| paper（纸底） | `#fbfaf7` 奶油 | `#fbfefc` 薄荷白 |
| amber-leaf-400（奖励） | `#d4a648` | `#febb32` |
| mist/moss/clay 三组 | 灰调 | 提饱和 |

★ 同时把散落在 4 个文件里的 **26 处硬编码旧色值**（MapPage / Onboarding /
LevelPage / ScoreView 的插画）一起换掉 —— 不换的话插画和新界面会两个色系。
另有两处 `rgb()` 字面量（VoiceComposer 的按钮投影、MapPage 的虚线）。

### 15.2 ★ 顺带修掉一个一直存在的可读性 bug

奖励按钮原来是**白字压金底**，对比度只有 **2.25:1**（底线 4.5:1）。
金底一提亮，白字只会更糟（1.70:1）。改成**深棕字压金底** → **7.2:1**。

## 十六、收尾：把 v3→v4 换色漏掉的 `rgb()` 字面色补干净

APK 复核时顺手做了一次「全量色值体检」，发现上一轮换色**只换了 hex**，
漏了 6 处 `rgb(r_g_b/…)` 形式的字面色（Tailwind 任意值写法）。

### 16.1 方法（这条最有复用价值）

```bash
grep -rhoE "rgb\([0-9]{1,3}[_ ][0-9]{1,3}[_ ][0-9]{1,3}" src | sort | uniq -c | sort -rn
```
把所有字面色列出来逐个对令牌 —— **比「搜旧 hex」可靠**，
因为 `rgb()` 里是十进制三元组，hex 搜索一个字都匹配不到。

### 16.2 漏掉的 6 处 → 映射

| 旧 | 位置 | 新 | 令牌 |
|---|---|---|---|
| `rgb(47_122_92)` | Onboarding:246 / ComposePage:893 主按钮投影 | `rgb(9_71_46)` | inkleaf-800 |
| `rgb(23_57_43)` | ui.tsx:313 / ComposePage:377 胶囊投影 | `rgb(9_71_46)` | inkleaf-800 |
| `rgb(97_149_183)` | LibraryPage:61 / SettingsPage:234 聚焦环 | `rgb(55_137_162)` | mist-500 |
| `rgb(77_125_140)` | App.tsx:443 info 发丝内边 | `rgb(39_107_131)` | mist-600 |
| `rgb(201 138 46)` | CardView:274 传说卡氛围光 | `rgb(236 158 6)` | amber-leaf-500 |
| `rgb(140 115 197)` | CardView:275 史诗卡氛围光 | `rgb(151 123 194)` | moss-400 |

两个刻意判断：
1. **主按钮投影用 800 不用 600** —— `btn-primary` 就是 `rgb(9 71 46)`，
   投影比底色深一档才立得住。跟设计系统对齐，别自己发明。
2. **史诗光用 moss-400 不用 500** —— 氛围光要比色块亮一档，
   500 在深色遮罩上会暗到看不见。

### 16.3 视觉核对

做了 2×2 对照图（旧/新 × 传说/史诗）截图看：金**变暖变跳**（符合「更亮更跳」），
紫几乎没变（刻意保住原意），白字在两者上都还清晰。

### 16.4 ★ 教训

**换主题色时，`hex` 和 `rgb()` 是两套写法，必须都搜。**
只搜 hex 会漏掉 Tailwind 任意值里的 `rgb(47_122_92/0.6)` 这种 ——
本轮就是靠 APK 复核才撞出来的。

## 十八、密码界面统一（家长反馈「好窄、别扭」）

家长原话：「另外 家长 密码 那里 样式 可以跟 日记 一样。现在的好像好窄 看起来别扭。」

### 18.1 根因：**同一个东西写了两遍，各写各的**

| | 日记本（家长认可） | 家长验证（被嫌窄） |
|---|---|---|
| 外层宽度 | `max-w-md`（448px） | **`max-w-xs`（320px）** |
| 卡片底 | 有（`Card`） | **没有**，浮在背景上 |
| 图标 | 圆形 56px + `anim-float` | 方块 64px，无动效 |
| 键盘按键 | `h-16 text-2xl` | `py-4 text-xl`（矮一截） |
| 按键布局 | `1-9 / 空 0 ⌫` | `1-9 / 清空 0 确定` |
| 圆点 | 14px `ink-150` | 16px `ink-300` |
| 底部 | 下划线小字 | 通栏按钮 |

「好窄」的直接原因就是那个 `max-w-xs` —— 而键盘自己本来就有 `max-w-xs`，
外层再窄一圈，键盘就像被"挤"在中间。

### 18.2 做法：抽成共用组件，而不是把样式抄过去

新建 `src/components/PinPad.tsx`，导出：
- `PinDots` —— 4 个圆点（已输入填实 / 出错整排抖）
- `PinKeypad` —— 数字键盘（**满 4 位自动提交，没有「确定」键**）
- `PinGate` —— 整页关卡：`max-w-md` + `Card` + 圆锁 + 标题 + 提示 + 圆点 + 键盘 + 底部小字
- `PIN_LINK_CLASS` —— 底部小字链接的统一样式

日记本删掉本地那两份，家长验证删掉本地 `PinPad`，两边都走 `PinGate`。

> ★ **抄样式只能修一次，抽组件才能不再走样。** 这次的 bug 本质就是复制粘贴，
> 所以修法也必须是把复制粘贴消掉。

### 18.3 顺手统一的行为差异

- **键盘**：家长那套原来有「清空 / 确定」两个键，而它**同时**又在满 4 位时自动提交
  —— 两套提交方式并存，冗余。已统一成日记的「自动提交 + ⌫ 退格」。
- **出错处理**：原来 900ms 清空、不响、红字也一起清掉。
  已按 `DiaryPage.failPin` **逐字对齐**：响一声 → 抖 **520ms** → 再清空；
  红字**保留到下一次按键**（用定时器清会没读完就没了）。

### 18.4 验证

- 也截了「输错密码」态：4 个点实心 + 红字 + 键盘变灰禁用，符合预期
