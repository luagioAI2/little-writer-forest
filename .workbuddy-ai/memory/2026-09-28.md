## 4. 照片去重：27 个重复 id → 30 张全部换新

### 坑
- ⚠️⚠️ **Python 写文本文件默认把 `\n` 翻成 `\r\n`** → bash `while read` 拿到的 `$url` 尾巴带 `\r`
